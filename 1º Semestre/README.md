# 📚 1º Semestre – Análise e Desenvolvimento de Sistemas

Este diretório reúne materiais, exercícios, projetos e anotações desenvolvidos durante o **primeiro semestre do curso de Análise e Desenvolvimento de Sistemas**.

O objetivo é documentar minha evolução na área de tecnologia e manter um registro organizado do que foi aprendido ao longo da graduação.

---

## 🐍 Técnicas de Desenvolvimento de Algoritmos
Introdução à lógica de programação utilizando **Python**.

Conteúdos estudados:

- Conceitos básicos de algoritmos
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Listas e outras estruturas de dados básicas
- Resolução de problemas com programação

---

## ⚙️ Engenharia de Software
Introdução aos conceitos fundamentais da **engenharia de software** e do desenvolvimento estruturado de sistemas.

Conteúdos estudados:

- Ciclo de vida de software
- Levantamento de requisitos
- Documentação de sistemas
- Modelagem com **UML**
- Diagramas (casos de uso, classes, etc.)
- Boas práticas de desenvolvimento

---

## 🌐 Programação Web
Fundamentos do desenvolvimento de aplicações para a web.

Tecnologias utilizadas:

- **HTML** – Estruturação de páginas web
- **CSS** – Estilização e layout
- **JavaScript** – Interatividade e manipulação do DOM

Principais conceitos:

- Estrutura de páginas web
- Estilização com CSS
- Manipulação de elementos com JavaScript
- Noções básicas de desenvolvimento front-end

---

## 💻 Sistemas Operacionais
Estudo dos conceitos fundamentais relacionados ao funcionamento de computadores e sistemas operacionais.

Conteúdos abordados:

- Conceitos de **hardware e software**
- Componentes de um computador
- Funcionamento de sistemas operacionais
- Gerenciamento de recursos
- Noções de arquitetura de computadores
