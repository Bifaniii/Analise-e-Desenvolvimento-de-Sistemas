# 📐 Análise e Projeto de Sistemas I

## 📖 Sobre a matéria

Disciplina focada em modelagem de sistemas utilizando **UML (Unified Modeling Language)**, trabalhando a representação visual de requisitos, processos e estruturas antes da fase de implementação.

## 🧠 Conteúdos trabalhados

- Diagramas de Caso de Uso
- Diagramas de Classe
- Diagramas de Sequência
- Diagramas de Atividade
- Boas práticas de modelagem e documentação de sistemas

## 🎯 Aprendizados

Reforço da importância de planejar e documentar um sistema antes de sair escrevendo código — pensar na estrutura, nos atores e nos fluxos de forma visual ajuda a evitar retrabalho na etapa de desenvolvimento.
