# 🌱 Itinerário

## 📖 Sobre a matéria

Disciplina presente em todos os semestres do curso, com o objetivo de aplicar os conhecimentos técnicos em um **projeto de impacto social**, desenvolvido em grupo para atender uma necessidade real da comunidade.

## 💡 O projeto

Desenvolvimento de um **site educativo para ensinar Python a crianças** atendidas por uma ONG, com conteúdo didático e atividades introdutórias de programação voltadas para o público infantil.

🔗 **Acesse o projeto:** [Projeto Touca](https://projeto-touca.onrender.com/)

## 🛠 Tecnologias utilizadas

`Node.js` `HTML` `CSS` `JavaScript`

## 👥 Minha atuação

Este projeto foi desenvolvido por outros integrantes do grupo; minha contribuição neste trabalho específico foi organização e apresentação.

## 🎯 Aprendizados

Acompanhamento de como transformar um conteúdo técnico (programação) em algo acessível e didático para um público iniciante e infantil, além da experiência de planejamento de um projeto com propósito social.
