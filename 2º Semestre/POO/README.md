# ☕ Programação Orientada a Objetos (POO)

## 📖 Sobre a matéria

Disciplina introdutória aos conceitos de Orientação a Objetos utilizando **Java**. Como já tinha experiência prévia com a linguagem, o semestre serviu mais como reforço formal dos conceitos e prática de exercícios do que como primeiro contato.

## 🧠 Conteúdos trabalhados

- Classes, objetos, atributos e métodos
- Encapsulamento, herança e polimorfismo
- Construtores e sobrecarga de métodos
- Interfaces e classes abstratas
- Exercícios práticos em Java

## 🎯 Aprendizados

Consolidação dos pilares da Orientação a Objetos, servindo de base direta para o que viria em Tópicos Avançados de Informática, onde apliquei Java em um projeto real com Spring Boot.
