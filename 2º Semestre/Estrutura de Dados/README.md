# 🧱 Estrutura de Dados

## 📖 Sobre a matéria

Disciplina introdutória sobre estruturas de dados fundamentais, com foco teórico em conceitos de organização e manipulação de dados em memória.

## 🧠 Conteúdos trabalhados

- Pilhas (Stack) — estrutura LIFO
- Filas (Queue) — estrutura FIFO
- Conceitos de inserção e remoção de elementos
- Aplicações práticas dessas estruturas em algoritmos

## 🎯 Aprendizados

Boa parte do aprofundamento nesses conceitos foi feita por conta própria, complementando o material de aula com estudo individual sobre pilhas, filas e suas aplicações práticas em programação.
