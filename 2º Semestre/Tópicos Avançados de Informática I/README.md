# 🚀 Tópicos Avançados de Informática

## 📖 Sobre a matéria

Uma das disciplinas mais importantes do semestre: foi aqui que desenvolvi, em grupo, meu **primeiro sistema completo e funcional em produção**, com backend, frontend, autenticação, integração com IA e deploy real. O Fly AI!

## 💡 O projeto

Sistema web de **planejamento de viagens com IA**: o usuário se cadastra, faz login, preenche um formulário com informações sobre a viagem desejada e recebe um **roteiro gerado por IA** com base nesses dados.

🔗 **Acesse o projeto:** [Fly-AI](https://flyai-v4.vercel.app/)

### Funcionalidades
- Cadastro e autenticação de usuários (JWT)
- Formulário de preferências de viagem
- Geração de roteiro personalizado via IA (Google Gemini)
- Aplicação publicada em ambiente de produção (deploy real)

## 👨‍💻 Minha atuação

Atuei em praticamente tudo, com exceção do frontend (feito por um colega de grupo):

- **Backend**: desenvolvimento da API com Java e Spring Boot
- **Segurança**: autenticação e autorização com Spring Security e JWT
- **Integração com IA**: consumo da API do Gemini para geração dos roteiros
- **Serialização de dados**: uso do Jackson
- **Conexão com o frontend**: integração da API com a interface (HTML, CSS, JS e Node)
- **Infraestrutura e deploy**: publicação da aplicação (frontend na Vercel, backend no Render), incluindo containerização com Docker

## 🛠 Tecnologias utilizadas

`Java` `Spring Boot` `Spring Web` `Spring Security` `JWT` `Jackson` `API Gemini` `Docker` `Vercel` `Render` `HTML` `CSS` `JavaScript` `Node.js`
